# ShopProject — контрольная работа №2

Учебный многостраничный сайт магазина аксессуаров для рабочего места, созданный на основе [контрольной работы №1](https://github.com/shebaketerayo/kr1-html-css-shop).

## Страницы

- `index.html` — главная и подборка товаров;
- `catalog.html` — каталог;
- `product.html` — карточка товара (товар выбирается параметром `id`);
- `order.html` — форма заявки и выбранный товар;
- `contacts.html` — учебные контакты.

## Технологии и запуск

HTML5, CSS3, JavaScript и Bootstrap 5.3.3. Стили Bootstrap и Bootstrap Bundle (JavaScript и Popper) подключены локально из `vendor/bootstrap/`, поэтому сайт работает без интернета. Собственное оформление находится в `custom.css`, изображения — в `images/`, логика — в `js/main.js`.

Чтобы запустить сайт, откройте `index.html` в браузере или запустите простой локальный сервер в папке проекта: `python -m http.server 8000`. Затем откройте `http://localhost:8000/`.

Используются сетка Bootstrap, навигационная панель, карточки, кнопки, формы, таблица и модальное окно. Форма проверяет поля в браузере и показывает демонстрационное подтверждение; данные никуда не отправляются.
